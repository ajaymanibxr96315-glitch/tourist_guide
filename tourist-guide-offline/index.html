About TravelGuide

TravelGuide is a front-end travel guide built with HTML, CSS, and JavaScript. Browse destinations, learn when to visit, explore attractions, discover local dishes, find local stays, and create an itinerary in your browser.

Network requirements

Works offline: destination data, saved favourites, recently viewed places, travel passport, journal, local admin records, search, filters, trip planner, food guide, and stay guide.

Requires internet: online attraction photos, live map tiles, and Google Maps directions/search.

When offline, destination details remain available and an illustrated Jaipur street map is shown. Its streets and pins are approximate; live turn-by-turn directions need a connection.

Features in this demo

✓ Destination search across regions, interests, attractions, and dishes, with sorting and budget filters

✓ Detailed destination pages with attractions, visit hours, expenses, and safety tips

✓ Interactive MapLibre map with OpenStreetMap-based OpenFreeMap tiles

✓ Google Maps directions for each selected landmark

✓ Current location centering

✓ Nearby place search using Google Maps

✓ Illustrated offline Jaipur street map

✓ Day-wise trip planner with budget estimate

✓ Print or save the complete multi-day itinerary as PDF, or export JSON

✓ Favourites and recently viewed destinations saved in this browser

✓ Dark mode with saved appearance preference

✓ Digital passport with visited stamps, badges, and a photo journal

✓ Local demo admin dashboard for destination records, feedback, and data checks

✓ Stay and food guide with category filters

✓ PWA manifest and service worker for static asset caching

External services used

🗺 OpenFreeMap — live vector map tiles using OpenStreetMap data. No API key. About the public map service.

🔵 MapLibre GL JS — open-source map renderer. No API key.

🚗 Google Maps URLs — search and directions links; no API key required. Documentation.

🖼 Wikipedia page images — landmark thumbnails load from matching attraction articles when online.

🔤 Google Fonts — Inter & Playfair Display. No API key.
